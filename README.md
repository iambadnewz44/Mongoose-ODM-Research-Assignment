# React Styling Assignment

A responsive developer portfolio built with React to demonstrate modern styling techniques.

## Assignment Requirements Covered

- UI/UX principles
- Inline styles in React
- Styled Components
- CSS-in-JS with Emotion
- Flexbox
- CSS Grid
- Media queries
- Responsive design
- Reusable React components
- Clean project structure

## Technologies

- React
- Vite
- JavaScript
- CSS3
- Styled Components
- Emotion

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for Production

```bash
npm run build
```

## Styling Techniques

### 1. Inline Styles
The Hero component uses a React style object for the main heading.

### 2. Styled Components
The project uses Styled Components for reusable buttons and project cards.

### 3. Emotion
Emotion's `css` helper is used for the animated badge in the hero section.

### 4. Flexbox
Navigation, skill pills, buttons, and contact/footer layouts use Flexbox.

### 5. CSS Grid
The hero, about section, and project cards use CSS Grid.

### 6. Media Queries
The layout changes at tablet and mobile breakpoints to improve usability on smaller screens.
